# BCN1 Issue Tracker

Mapa interactivo de incidencias para BCN1 — muelles, garitas, plazas, infraestructura.

## Deploy en Render
1. Sube esta carpeta a un repo GitHub
2. En Render → New → Static Site
3. Conecta el repo, publish directory: `.`
4. Deploy

## Uso
- Verde = sin incidencia
- Rojo = TT abierto (con link al TT)
- Ámbar = en seguimiento
